## Featured project: HosieryLab

<a href="https://hosierylab.com"><img src="https://github-readme-stats.vercel.app/api/pin/?username=aurora-ai-lab&repo=hosierylab&theme=transparent&hide_border=true&title_color=C42E47&text_color=6F6260&icon_color=D9B68C" alt="HosieryLab repository card" /></a>

HosieryLab is a **website-first visual reference and prompt library**. Each specimen separates the variables that image models usually blur together:

- **D number and opacity** — from ultra-sheer to opaque
- **Color and finish** — black, white, neutrals, satin, matte, gloss, and more
- **Construction** — pantyhose, knee-highs, thigh-highs, welt, toe, heel, knit, and pattern
- **Prompt layers** — full-body context and a focused hosiery specification
- **Machine access** — image and prompt records are served through the website so people can use the same source in a workflow or MCP client

## A simple workflow

```text
Choose a specimen  →  inspect the image  →  copy one prompt layer  →  render  →  compare the result
```

The point is control: change one hosiery variable at a time, keep the rest of the scene stable, and build a repeatable visual language.
